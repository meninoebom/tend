# Building Tend in Public

A developer learning to be a founder, one feature at a time.

Each entry captures what was built, what was learned, and the product thinking behind it. Not a changelog — a learning journal. Written for future employers and other builders who want to see how products actually get made.

**Stack:** Next.js + FastAPI + PostgreSQL, deployed on Railway.
